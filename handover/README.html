交接文档概述

本目录包含 Studio Blender 插件项目的功能交接文档。每篇文档详细介绍了特定功能模块的实现原理、技术要点和使用说明。

文档结构

每个功能模块都包含两种格式的文档：

  • .md 文件：原始 Markdown 格式，方便代码编辑器查看和编辑
  • .html 文件：美化后的网页格式，可直接在浏览器中打开查看，带有目录导航和美观排版
注意：.md 和 .html 文件内容如有不同，以 .md 文件为准。
