# 📋 Studio Blender 项目离职交接说明

## 交接文档概述

本目录包含 Studio Blender 插件项目的功能交接文档。每篇文档详细介绍了特定功能模块的实现原理、技术要点和使用说明。

## 文档结构

每个功能模块都包含两种格式的文档：

- **`.md`** **文件**：原始 Markdown 格式，方便代码编辑器查看和编辑
- **`.html`** **文件**：美化后的网页格式，可直接在浏览器中打开查看，带有目录导航和美观排版

> **注意**：`.md` 和 `.html` 文件内容如有不同，以 `.md` 文件为准。

## 功能模块

> 说明：一个文档可归属于多个分类，从不同维度组织内容。

- **LED灯光控制系统**：无人机灯光颜色控制的核心逻辑

- **保留刷光效果**：刷光功能的保持逻辑

### ✈️ 编队与路径

- **计算分组起飞** / **计算分组降落**：编队起飞降落的分组算法
- **重算分组起飞**：重新计算分组起飞位置
- **起飞网格重分配**：起飞位置的网格分配逻辑
- **安全路径计算**：安全飞行路径的规划算法
- **轨迹验证**：飞行轨迹的合法性检查
- **星云模式**：星云模式的实现逻辑

### 🧮 核心算法

- **编队过渡匹配算法**：编队过渡的匹配逻辑
- **物体内部检测函数**：空间检测算法
- **图片导入算法**：图像数据的解析与处理
