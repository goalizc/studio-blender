# 安全路径计算 Calculate Safe Path 交接文档

## 1. 概述

**类名**: `SkybrushCalculateSafePathOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/calculate_safe_path.py`

**功能**: 自动解决无人机编队在指定帧范围内的空间碰撞问题。算法会逐帧检测无人机间距，对距离过近的无人机对执行**空间分离**，并插入位置关键帧。采用**动态多遍精化策略**，从粗粒度到细粒度逐步收敛，确保全程满足最小安全距离。

## 3. 核心算法逻辑

### 3.1 冲突检测：[`find_nearby_objects`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/operators/calculate_safe_path.py#L17-L22)

```python
def find_nearby_objects(positions, min_distance):
    distances = np.sqrt(((positions[:, np.newaxis] - positions)**2).sum(axis=2))
    upper_triangle_mask = np.triu(np.ones((num_objects, num_objects), dtype=bool), k=1)
    too_close = np.where((distances < min_distance) & upper_triangle_mask)
    return [(i, j, distances[i, j]) for i, j in zip(too_close[0], too_close[1])]
```

**算法原理**:
1. **广播计算距离矩阵**: `O(N²)` 一次性计算所有无人机两两之间的欧氏距离
2. **上三角掩码**: `np.triu(..., k=1)` 剔除对角线（自身距离为0）和下三角（重复计算），只保留 `i < j` 的配对
3. **阈值过滤**: 筛选距离 `< min_distance` 的冲突对，返回 `(i, j, 实际距离)` 列表

### 3.2 冲突分离：[`adjust_object_positions`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/operators/calculate_safe_path.py#L24-L61)

```python
def adjust_object_positions(objects, min_distance):
    positions = np.array([get_position_of_object(obj) for obj in objects], dtype=np.float64)
    adjusted_indices = set()

    while True:
        nearby_pairs = find_nearby_objects(positions, min_distance)
        if not nearby_pairs: break
        nearby_pairs.sort(key=lambda x: x[2])  # 按距离升序，优先处理最接近的对

        current_adjusted = set()
        for i, j, current_dist in nearby_pairs:
            if i in adjusted_indices and j in adjusted_indices:
                continue  # 本轮已调整过的不再重复处理

            # 水平分离向量
            direction = positions[j] - positions[i]
            direction /= np.linalg.norm(direction)
            move_dist = direction * (MARGIN + min_distance - current_dist) / 2
            
            # 垂直分离偏移
            axis_dist = math.copysign(0.1, direction[2]) * (min_distance - current_dist)

            positions[i] -= move_dist; positions[i][2] -= axis_dist
            positions[j] += move_dist; positions[j][2] += axis_dist
            current_adjusted.update([i, j])

        if not current_adjusted: break
        adjusted_indices.update(current_adjusted)

    # 应用并插入关键帧
    for idx in adjusted_indices:
        objects[idx].location = positions[idx]
        objects[idx].keyframe_insert(data_path="location", frame=bpy.context.scene.frame_current)
    return len(adjusted_indices)
```

**核心设计**:
| 机制 | 说明 |
|------|------|
| **贪心优先** | 按距离升序排序，优先推开最接近的无人机，避免连锁反应 |
| **等量分离** | 各移动 `(目标距离 - 当前距离 + MARGIN) / 2`，保持对称性 |
| **垂直偏移** | Z 轴额外施加 `±0.1 × 间隙` 的偏移，利用高度差化解平面密集冲突 |
| **防重复调整** | `adjusted_indices` 记录本帧已调整的索引，避免同一帧内被多次推挤导致位置漂移 |
| **仅移动冲突方** | 未发生冲突的无人机保持原轨迹不变，仅对冲突对插入关键帧 |

### 3.3 动态多遍精化：[`create_dynamic_drone_animation`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/operators/calculate_safe_path.py#L83-L104)

```python
def create_dynamic_drone_animation(start_frame, end_frame, safety_dist, adjust_rate):
    frame_interval = 1 if adjust_rate == 1 else math.ceil((end_frame - start_frame) / 4.0)
    while True:
        iteration += 1
        adjusted = create_drone_animation(start_frame, end_frame, safety_dist, frame_interval)
        no_adjust_count = 0 if adjusted else no_adjust_count + 1
        if (frame_interval == 1 and adjusted == 0) or no_adjust_count >= 3:
            break
        if frame_interval > 1:
            frame_interval = math.floor(frame_interval * adjust_rate)
```

**收敛策略**:
1. **初始粗采样**: 帧间隔初始为总范围的 1/4（例如 100 帧范围，初始间隔 25 帧）
2. **逐遍加密**: 每完成一遍，`frame_interval = floor(interval × adjust_rate)`。默认 `adjust_rate=0.9`，间隔每次缩小 10%
3. **提前终止**: 连续 3 遍无任何调整，说明编队已稳定，提前退出
4. **最终精修**: 当 `frame_interval == 1` 且无调整时，达到帧级精度，算法结束

**收敛示例** (`adjust_rate = 0.9`, 范围 100 帧):
| 迭代次数 | 帧间隔 | 采样帧数 | 说明 |
|----------|--------|----------|------|
| 1 | 25 | 4 帧 | 粗调大范围冲突 |
| 2 | 22 | ~4 帧 | 继续收紧 |
| 3 | 19 | ~5 帧 | ... |
| ... | ... | ... | ... |
| N | 1 | 100 帧 | 逐帧精修，确保全程无碰撞 |

## 5. 数学与物理模型

### 5.1 分离向量计算

目标：使无人机 `i` 和 `j` 的间距达到 `min_distance + MARGIN`

```
分离量 Δd = (min_distance + MARGIN) - current_dist
单位向量 u = (Pj - Pi) / ||Pj - Pi||
Pi_new = Pi - (Δd / 2) * u - (0.1 * Δd * sign(u_z) * k)
Pj_new = Pj + (Δd / 2) * u + (0.1 * Δd * sign(u_z) * k)
```

其中 `MARGIN = 0.03` 为防止浮点误差和动画插值导致二次碰撞的缓冲余量。

### 5.2 Z 轴偏移意义

```python
axis_dist = math.copysign(0.1, direction[2]) * (min_distance - current_dist)
```

- 当 `direction[2] > 0`（j 在 i 上方），j 额外上升，i 额外下降
- 利用垂直空间化解水平密集冲突，减少“平面推挤震荡”
- 系数 `0.1` 保证垂直偏移远小于水平分离，避免高度突变

## 8. 性能特征与限制

### 8.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 距离矩阵 | O(N²) | 每帧计算 |
| 冲突分离迭代 | O(K × N²) | K 为内部 while 循环次数（通常 < 5） |
| 多遍精化 | O(M × F × N²) | M 为迭代遍数，F 为每遍采样帧数 |

### 8.2 已知限制

| 限制 | 说明 |
|------|------|
| **不保证全局最优** | 贪心策略仅局部推开，可能产生次优路径或轻微抖动 |
| **覆盖原有动画** | 对冲突无人机插入的关键帧会覆盖原有轨迹上的对应帧 |
| **密集编队性能** | 大规模 (>500) 或极度密集的编队会导致 O(N²) 计算耗时显著增加 |
| **Z 轴偏移累积** | 多次调整可能导致无人机高度轻微偏离原始设计 |

## 9. 调试验证方法

1. 执行前备份原始动画
2. 在较小帧范围（如 10 帧）测试，观察控制台输出

5. 使用 Safety Check 面板验证最小距离是否全程 ≥ `safety_dist`

## 10. 常见问题 FAQ

### Q1: `adjust_rate` 参数如何影响结果？

- `adjust_rate = 1.0`: 直接从第 1 帧开始逐帧计算，最精确但最慢
- `adjust_rate = 0.5`: 初始间隔大，收敛快，可能遗漏中间帧的细微冲突
- 默认 `0.9`: 平衡精度与性能，适合大多数编队

### Q2: 为什么只移动冲突的无人机？

为了最小化对原始编队轨迹的破坏。未冲突的无人机保持原设计路径，仅冲突双方被推开。这也意味着如果 A 和 B 冲突，C 和 D 不冲突，最终 A/B 路径改变，C/D 路径不变。

### Q3: MARGIN (0.03) 的作用是什么？

Blender 的关键帧插值（如贝塞尔曲线）可能在两个关键帧之间产生轻微偏离。`MARGIN` 提供 3cm 的缓冲余量，确保插值过程中的实际距离不会跌破 `safety_dist`。

### Q4: 算法会修改无人机的旋转或缩放吗？

不会。仅修改 `location` 属性并插入位置关键帧。旋转、缩放和颜色动画保持原样。

### Q5: 连续 3 次无调整就退出，会不会漏检？

不会。`no_adjust_count` 仅在**同一帧间隔**下连续无调整时累加。如果已经稳定，说明当前采样密度下无冲突。继续缩小间隔也不会产生新冲突（因为距离场是连续的）。这是一种有效的早停优化。
