1. 概述

类名: SkybrushHHImportImageOperator

文件路径: src/modules/sbstudio/plugin/operators/import_image.py

功能: 将图像文件转换为无人机编队的位置点云。算法通过分析图像的灰度分布，自动提取前景/背景区域，将背景区域（即图像的非主体部分）转换为无人机的空间位置。支持形态膨胀和自适应圆点检测两种模式，适用于不同的图像类型。

3. 核心算法逻辑

3.1 执行流程总览

invoke() → 弹出文件选择器
    ↓
execute() → 加载图像并处理
    ↓
1. 加载图像，提取灰度通道
2. 基于中位数 + 标准差计算背景阈值
3. 生成二值掩码（True = 背景区域）
    ↓
┌─ adaptive=False（膨胀模式）:
│  1. 迭代膨胀前景区域
│  2. 提取连通区域质心作为无人机位置
│
└─ adaptive=True（自适应模式）:
   1. 连通块标记 + 面积中位数估算圆点直径
   2. 距离变换 + 高斯平滑
   3. 局部极大值检测圆点中心
   4. 坐标后处理去重
    ↓
4. 计算点云最小间距，按比例缩放至 min_distance
5. 创建网格对象（存储无人机位置）
6. 创建图像参考对象（Empty，显示原始图像）
7. 将参考对象放入"图片"集合

3.2 灰度分析与背景提取

pixels = np.asarray(image.pixels, dtype=np.float32).reshape(width * height, 4)
img_gray = pixels[:, :3].mean(axis=1, dtype=np.float32)           # RGB → 灰度
base, threshold = np.median(img_gray), img_gray.std() * self.threshold
lower, upper = base - threshold, base + threshold
pixels = np.logical_and(img_gray > lower, img_gray < upper).reshape(height, width)

算法原理:

  1. 将 RGBA 像素转为灰度（RGB 三通道均值）
  2. 计算灰度中位数 base 和标准差 threshold
  3. 灰度在 [base - threshold, base + threshold] 范围内的像素标记为背景（True）
  4. 其余像素标记为前景（False）

直观理解: 假设图像主体是白色文字、黑色背景。中位数可能是黑色（背景色），标准差反映灰度变化范围。白色文字的灰度远超 base + threshold，因此不会被标记为背景。

3.3 膨胀模式（非自适应）

形态膨胀 execute 第83-92行

for _ in range(self.iterations):
    padded = np.pad(pixels, 1, mode='edge')    # 边界填充，防止越界
    neighbors = np.zeros_like(pixels, dtype=np.bool_)
    neighbors |= padded[1:-1, 0:-2] | padded[1:-1, 2:]    # 左 + 右
    neighbors |= padded[0:-2, 1:-1] | padded[2:, 1:-1]    # 上 + 下
    if self.structure == "DIR8":
        neighbors |= padded[0:-2, 0:-2] | padded[0:-2, 2:] | \
                     padded[2:, 0:-2] | padded[2:, 2:]     # 对角线
    pixels |= neighbors

膨胀操作: 将前景像素的邻居也标记为前景。相当于"扩大"前景区域。

方向邻居位置代码
4方向左、右、上、下padded[1:-1, 0:-2] 等
8方向4方向 + 左上、右上、左下、右下padded[0:-2, 0:-2] 等

膨胀效果: 前景区域每迭代一次扩大一圈。多次迭代后，原本分离的前景区域会合并成更大的连通块。

质心提取 centroid 方法

@staticmethod
def centroid(pixels, x, y):
    height, width = pixels.shape
    points = []
    def scan(points, x, y):
        P, X = [], x + 1
        while x >= 0 and not pixels[y, x]:
            P.append(x); pixels[y, x], x = True, x - 1   # 向左扫描，标记已访问
        while X < width and not pixels[y, X]:
            P.append(X); pixels[y, X], X = True, X + 1   # 向右扫描，标记已访问
        if y > 0:
            [pixels[y - 1, x] or scan(points, x, y - 1) for x in P]   # 向上递归
        if y + 1 < height:
            [pixels[y + 1, x] or scan(points, x, y + 1) for x in P]   # 向下递归
        points += [(x, y) for x in P]
    scan(points, x, y)
    return np.mean(points, axis=0) + 0.5

算法: 从前景像素 (x, y) 出发，使用深度优先搜索遍历整个连通的前景区域，计算区域中心（质心）。

工作流程:

  1. 从种子像素向左、右扫描，收集同一行中所有连续的前景像素
  2. 对每个收集到的像素，递归检查上、下行的相邻像素
  3. 标记已访问的像素（pixels[y, x] = True），避免重复遍历
  4. 返回连通区域的平均坐标 + 0.5（像素中心偏移）

调用方式:

points = np.array([self.centroid(pixels, x, y)
    for y in range(height) for x in range(width) if not pixels[y, x]])

遍历所有前景像素，每个连通区域只处理一次（因为扫描过程中会标记已访问）。

3.4 自适应圆点检测

检测流程 detect_dots_adaptive 方法

@staticmethod
def detect_dots_adaptive(ndimage, binary):
    # 1. 连通块标记
    label_im, nb_labels = ndimage.label(binary)
    
    # 2. 估算圆点直径（面积中位数法）
    sizes = ndimage.sum(binary, label_im, range(1, nb_labels + 1))
    avg_area = np.median(sizes)
    estimated_d = 2 * np.sqrt(avg_area / np.pi)
    
    # 3. 距离变换 + 高斯平滑
    distance = ndimage.distance_transform_edt(binary)
    sigma_val = estimated_d / 8
    smoothed_dist = ndimage.gaussian_filter(distance, sigma=sigma_val)
    
    # 4. 局部极大值检测
    filter_size = int(estimated_d / 3)
    local_max = ndimage.maximum_filter(smoothed_dist, size=filter_size) == smoothed_dist
    local_max = local_max & (smoothed_dist > estimated_d * 0.2)
    
    # 5. 坐标去重
    return filter_close_points(raw_centers, min_sep=estimated_d / 3)

适用场景: 图像中包含离散的圆形标记（如圆点、十字、光斑），每个圆点需要映射为一架无人机的位置。

步骤详解

步骤方法作用
1. 连通块标记ndimage.label将二值图像中的连通区域编号，得到标记矩阵和标签数量
2. 直径估算ndimage.sum + median计算每个连通块的面积，取中位数。使用中位数可以排除重叠块（面积过大）和噪点（面积过小）的干扰。d = 2√(area/π)
3. 距离变换distance_transform_edt计算每个前景像素到最近背景像素的欧氏距离。圆心的距离值最大。
4. 高斯平滑gaussian_filter平滑距离图，消除圆点内部的局部波动，使峰值更明显。sigma ≈ d/8
5. 局部极大值maximum_filter在每个 filter_size ≈ d/3 的窗口内找到距离最大值，即为圆点中心
6. 坐标去重filter_close_points贪婪去重：依次取点，移除所有距离太近的点。min_sep ≈ d/3

距离变换示意图

原始圆点 (二值):          距离变换后:
   █████                   0 0 0 0 0 0 0
   █   █                   0 1 2 3 2 1 0
   █ O █       →           0 2 4 5 4 2 0
   █   █                   0 1 2 3 2 1 0
   █████                   0 0 0 0 0 0 0
                               ↑ 最大值=圆心

3.5 点云缩放

if len(points) > 1:
    dist_matrix = np.linalg.norm(points[:, np.newaxis] - points, axis=2)
    np.fill_diagonal(dist_matrix, np.inf)
    scale = self.min_distance / np.min(dist_matrix)
else:
    scale = 1.0

缩放原理:

  1. 计算点云中所有点对之间的欧氏距离矩阵
  2. 对角线（自身距离）设为无穷大，避免影响最小值
  3. 找到最小间距 min_dist
  4. 缩放因子 scale = min_distance / min_dist

效果: 缩放后，点云中最接近的两架无人机的间距恰好等于 min_distance。

3.6 网格与图像对象创建

网格对象（无人机位置）

mesh = bpy.data.meshes.new("mesh_" + filename)
mesh.vertices.add(len(points))
mesh.vertices.foreach_set("co", np.insert(points * scale, 1, 0, axis=1).flatten())
bpy.context.scene.collection.objects.link(bpy.data.objects.new(filename, mesh))
  • 创建空网格，顶点数 = 点数
  • 将 2D 图像坐标 (x, y) 转为 3D 坐标 (x, 0, y)（插入 Z=0）
  • foreach_set 批量设置顶点坐标，性能优于逐个赋值

图像参考对象（Empty）

empty = bpy.data.objects.new("image_" + filename, None)

4. 数学模型

4.1 坐标映射

图像像素 (px, py) → 3D 空间 (px × scale, 0, py × scale)
  • X 轴对应图像宽度方向
  • Z 轴对应图像高度方向
  • Y 轴固定为 0（水平地面）

4.2 距离变换

对于二值图像 B(x, y)：

D(x, y) = min{ ||(x,y) - (x',y')|| | B(x',y') = 0 }

即每个前景像素到最近背景像素的欧氏距离。

4.3 局部极大值检测

local_max(x, y) = (D_smoothed(x, y) == max{D_smoothed(u, v) | |u-x|≤size/2, |v-y|≤size/2})

在 size × size 的窗口内，如果当前像素的距离值最大，则认为是局部极大值。

8. 性能特征与限制

8.1 时间复杂度

操作复杂度说明
灰度转换O(W×H)一次遍历所有像素
膨胀迭代O(K × W×H)K 为迭代次数
质心提取O(W×H)每个像素最多被访问一次（标记机制）
距离矩阵O(N²)N 为点数
自适应检测O(W×H)基于 scipy 的高效实现

8.2 已知限制

限制说明
2D 映射仅生成平面（Y=0）上的位置，不支持 3D 图像导入
灰度依赖基于 RGB 均值提取灰度，对彩色前景/背景可能不准确
膨胀模式精度质心提取对不规则形状的连通区域可能产生偏差
自适应模式依赖 scipy未安装 scipy 时无法使用自适应模式
不支持撤销bl_options = {"REGISTER"} 不包含 UNDO
去重效率filter_close_points 使用 O(N²) 的贪婪策略，点数过多时较慢

10. 常见问题 FAQ

Q1: 为什么背景像素标记为 True，前景标记为 False？

算法的设计思路是：背景是连续的、大面积的区域，前景是分散的、小块的目标。将背景标记为 True 便于使用形态膨胀来"填充"前景区域之间的空隙，然后将填充后的区域分割为连通块。

Q2: threshold 参数如何影响结果？

  • threshold 越大，背景判定范围越宽，更多像素被标记为背景 → 前景区域越小 → 提取的点数越少
  • threshold 越小，背景判定范围越窄，更多像素被标记为前景 → 前景区域越大 → 提取的点数越多

Q3: 膨胀模式与自适应模式的区别？

对比膨胀模式自适应模式
适用场景文字、线条、连续图案离散圆点、光斑
算法形态膨胀 + 连通区域质心距离变换 + 局部极大值
精度中等（质心可能偏离视觉中心）高（精确检测圆点中心）
依赖纯 numpy需要 scipy
参数iterations, structure自动估算，无需手动调整

Q4: 为什么 Y 轴固定为 0？

图像是 2D 的，算法将其映射为 XZ 平面上的点云。Y 轴（垂直方向）固定为 0，后续可通过其他操作符（如起飞、编队变换）将无人机提升到空中。

Q5: 可以同时导入多张图像吗？

可以，每次执行操作符导入一张图像。每张图像会创建独立的网格对象和参考对象。

Q6: 缩放后的点云间距一定是 min_distance 吗？

缩放保证最接近的两架无人机间距等于 min_distance。其他无人机对的间距可能更大，取决于原始图像的像素分布。
