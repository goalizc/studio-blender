# 导出起飞位置 Export Takeoff Position 交接文档

## 1. 概述

**类名**: `SkybrushExportTakeoffPositionOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/export_takeoff_position.py`

**功能**: 将所有无人机在帧 1 的位置导出为 JSON 文件。

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.export_takeoff_position` |
| `bl_label` | Export takeoff position |
| `bl_description` | Export the drone takeoff position as a json file |
| `bl_options` | `REGISTER`, `UNDO` |

### 2.1 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `filepath` | StringProperty | "起飞位置.json" | 导出文件的保存路径 |

---

## 3. 核心逻辑

```
invoke() → 弹出文件保存对话框（默认文件名"起飞位置.json"）
    ↓
execute() → 导出位置
    ↓
1. 跳转到帧 1
2. 遍历所有无人机，获取位置
3. 将位置列表序列化为 JSON 并写入文件
```

### 3.1 JSON 格式

```json
[
  [x1, y1, z1],
  [x2, y2, z2],
  ...
]
```

每个元素为 `[x, y, z]` 三维坐标，按无人机在集合中的顺序排列。

---

## 4. 依赖关系

| 模块 | 用途 |
|------|------|
| `json` | JSON 序列化 |
| `sbstudio.plugin.constants.Collections` | 获取无人机集合 |
| `sbstudio.plugin.utils.evaluator` | 获取无人机位置 |
