帧延迟

基于空间位置差异自动生成波浪式时序编排的延迟算法

1. 概述

类名: SkybrushFrameDelayOperator

文件路径: src/modules/sbstudio/plugin/operators/frame_delay.py

功能: 根据选中无人机的空间位置差异，自动计算延迟帧数并偏移其选中的关键帧。实现基于空间的时序编排，使距离参考点较远的无人机延迟更长时间执行相同动作，从而形成波浪式、螺旋式等空间动画效果。

3. 核心算法逻辑

3.1 执行流程

invoke() → 设置 reference_frame 为当前帧，弹出参数对话框
    ↓
execute() → 执行帧延迟
    ↓
1. 调用 get_tool_function() 获取排序函数 key 和偏移计算函数 offset
2. 按 key 对选中无人机排序 → 得到 [obj_0, obj_1, obj_2, ...]
3. 取第一个无人机作为参考点 head_position
4. 遍历剩余无人机:
   - 计算与参考点的距离
   - 调用 offset() 计算延迟帧数
   - 调用 move_selected_frames() 偏移关键帧

3.2 工具函数生成：get_tool_function

def get_tool_function(self):
    # 1. 根据方向选择排序键
    if self.direction == "UP":
        key = lambda obj:  get_position_of_object(obj)[2]   # Z 升序
    elif self.direction == "DOWN":
        key = lambda obj: -get_position_of_object(obj)[2]   # Z 降序
    elif self.direction == "LEFT":
        key = lambda obj: -get_position_of_object(obj)[0]   # X 降序
    elif self.direction == "RIGHT":
        key = lambda obj:  get_position_of_object(obj)[0]   # X 升序
    elif self.direction == "FORWARD":
        key = lambda obj:  get_position_of_object(obj)[1]   # Y 升序
    elif self.direction == "BACKWARD":
        key = lambda obj: -get_position_of_object(obj)[1]   # Y 降序

    # 2. 计算延迟斜率：帧数/米
    level = self.delay_frames / self.unit_distance
    
    # 3. 根据方向选择距离计算维度
    if self.direction == "UP" or self.direction == "DOWN":
        offset = lambda a, b: math.ceil(abs(a[2] - b[2]) * level)  # Z 轴距离
    elif self.direction == "LEFT" or self.direction == "RIGHT":
        offset = lambda a, b: math.ceil(abs(a[0] - b[0]) * level)  # X 轴距离
    elif self.direction == "FORWARD" or self.direction == "BACKWARD":
        offset = lambda a, b: math.ceil(abs(a[1] - b[1]) * level)  # Y 轴距离

    return key, offset

设计模式: 工厂模式 —— 根据参数动态生成排序和偏移函数，避免重复代码。

3.3 延迟计算公式

delay = ceil(|position_target - position_reference| × (delay_frames / unit_distance))

示例计算:

  • unit_distance = 5m, delay_frames = 10
  • 参考无人机位置: (0, 0, 0)
  • 目标无人机位置: (0, 0, 15)
  • 延迟 = ceil(|15 - 0| × (10/5)) = ceil(30) = 30 帧

3.4 关键帧偏移：move_selected_frames

def move_selected_frames(self, obj, offset):
    if offset == 0: return
    
    # 偏移位置动画关键帧
    for fcurve in obj.animation_data.action.fcurves:
        for p in [p for p in fcurve.keyframe_points if p.select_control_point]:
            p.co.x += offset           # 控制点 X 坐标（帧号）
            p.handle_left.x += offset  # 左手柄 X 坐标
            p.handle_right.x += offset # 右手柄 X 坐标
    
    # 偏移材质动画关键帧（颜色、灯光等）
    for mat_slot in obj.material_slots:
        if mat_slot.material and mat_slot.material.use_nodes and \
           mat_slot.material.node_tree.animation_data is not None:
            for fcurve in mat_slot.material.node_tree.animation_data.fcurves:
                for p in [p for p in fcurve.keyframe_points if p.select_control_point]:
                    p.co.x += offset
                    p.handle_left.x += offset
                    p.handle_right.x += offset

偏移范围:

  1. 位置 F-Curve: 动画数据中的位置关键帧
  2. 材质 F-Curve: 灯光颜色、发射强度等材质动画

仅偏移选中的关键帧: p.select_control_point 确保只有用户在 Graph Editor/Dope Sheet 中选中的关键帧被移动，未选中的不受影响。

4. 数学模型

4.1 空间排序与延迟映射

排序后:  obj_0, obj_1, obj_2, ..., obj_n
位置:    pos_0, pos_1, pos_2, ..., pos_n

延迟:    delay(obj_i) = ceil(|pos_i[axis] - pos_0[axis]| × level)
无人机Z 坐标延迟计算延迟帧
obj_00mceil(0 × 2) = 00 帧
obj_13mceil(3 × 2) = 66 帧
obj_27mceil(7 × 2) = 1414 帧
obj_37.5mceil(7.5 × 2) = 1515 帧

4.2 F-Curve 手柄同步

p.co.x += offset
p.handle_left.x += offset
p.handle_right.x += offset

关键帧的控制点和左右手柄必须同步偏移，否则会破坏贝塞尔曲线的形状。只偏移 X（帧号）而不偏移 Y（值），保持动画值不变。

5. 实际应用场景

5.1 场景一：波浪起飞（Z 轴方向）

需求: 无人机从低到高依次起飞，形成波浪效果。

配置值
directionUP (Z+)
unit_distance5m
delay_frames10

效果: 低处无人机先起飞，高处无人机每 5m 延迟 10 帧起飞。

5.2 场景二：横向传递灯光（X 轴方向）

需求: 灯光颜色从左向右依次传递。

配置值
directionRIGHT (X-)
unit_distance3m
delay_frames5

效果: 左侧无人机先变色，右侧每 3m 延迟 5 帧变色。

5.3 场景三：螺旋前进（组合效果）

在 X/Y 两个方向分别应用帧延迟，可形成螺旋式前进的时序效果。

8. 性能特征与限制

8.1 时间复杂度

操作复杂度说明
排序O(N log N)N 为选中无人机数量
获取位置O(N)每架无人机调用一次 get_position_of_object
关键帧偏移O(N × K)K 为每架无人机的选中关键帧数量

8.2 已知限制

限制说明
仅支持单轴每次只能沿 X/Y/Z 之一方向排序，不支持复合方向（如对角线）
参考点固定始终以排序后的第一个无人机为参考点（距离为 0），用户无法自定义参考点
不处理负偏移由于使用 abs() 计算距离，所有延迟都是正数（向后偏移）
材质动画检测不完善如果材质没有 animation_data 或 action，会跳过该材质（is not None 检查）

10. 常见问题 FAQ

Q1: 参考帧 (reference_frame) 的作用是什么？

在当前实现中，reference_frame 不参与计算。它仅用于初始化对话框显示（设置为当前帧）。实际参考点是排序后的第一个无人机的空间位置。

Q2: 为什么只偏移 X 坐标（帧号）而不偏移 Y 坐标（值）？

因为帧延迟的目的是改变动作发生的时机，而不改变动作的幅度。位置值、颜色值等保持不变，只在时间轴上平移。

Q3: 可以对非选中的关键帧生效吗？

不行。代码中明确检查 p.select_control_point，只有选中的关键帧才会被偏移。这是为了允许用户精细控制哪些关键帧参与延迟。

Q4: unit_distance = 0 时会发生什么？

level = delay_frames / 0 会触发 ZeroDivisionError。参数设置了 min=0，但实际使用中应确保 unit_distance > 0。

Q5: 延迟帧数可以为负数吗？

不可以。delay_frames 参数设置了 min=0，且 math.ceil(abs(...)) 确保结果始终为非负数。所有无人机相对于参考点的延迟都是向后偏移（帧号增大）。

Q6: 如何实现"提前"效果？

可以先将关键帧整体向后偏移足够多的帧，然后对靠近参考点的无人机应用较小的正向偏移，形成"相对提前"的视觉效果。或者手动在 Dope Sheet 中反向移动关键帧。
