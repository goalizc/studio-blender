# SkybrushSelectFileOperator 交接文档

## 1. 概述

**类名**: `SkybrushSelectFileOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/hhang_operators.py`

**功能**: 通用文件选择器，配合 `ImportHelper` 实现文件浏览选择，将选择的文件路径保存到场景设置中。

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.select_file` |
| `bl_label` | Select file |
| `name` | StringProperty (HIDDEN) — 目标属性名 |
| `filter_glob` | StringProperty (HIDDEN) — 文件过滤模式，如 `*.json;*.txt` |

---

## 3. 核心逻辑

```
execute() → 将 filepath 保存到设置
    ↓
┌─ 如果 name 为空: 保存到 filepath
└─ 否则: 保存到 settings.name 属性
```

---

## 4. 使用方式

在其他 Operator 的 `draw` 方法中调用：
```python
sf = row.operator("skybrush.select_file", text="", icon="FILEBROWSER")
sf.name = "filepath"          # 目标属性名
sf.filter_glob = "*.json"     # 文件过滤
```
