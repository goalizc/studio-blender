# SkybrushReplaceCopyLocationConstraintOperator 交接文档

## 1. 概述

**类名**: `SkybrushReplaceCopyLocationConstraintOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/hhang_operators.py`

**功能**: 将帧范围字符串解析为具体帧号，获取每架无人机在这些帧的实际位置并插入关键帧，然后移除 Copy Location 约束，将约束位置固化为显式关键帧。

---

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.replace_copy_location_constraint` |
| `bl_label` | Replace Copy Location Constraint |
| `bl_options` | `REGISTER`, `UNDO` |

---

## 3. 核心逻辑

### 3.1 帧范围解析

`parse` 方法支持三种帧范围格式：

| 格式 | 示例 | 含义 | 返回模式 |
|------|------|------|----------|
| 单帧 | `100` | 仅第100帧 | 模式1 |
| 范围 | `10-200` | 第10帧到第200帧（逐帧） | 模式2 |
| 步进范围 | `10-200:5` | 第10帧到第200帧，每5帧取一帧 | 模式3 |

```python
pattern = r'^(?:(\d+)|(\d+)-(\d+)|(\d+)-(\d+):(\d+))$'
```

### 3.2 执行流程

```
execute() → 解析帧范围并替换约束
    ↓
1. 遍历 frame_range 中每个子串（逗号分隔）
2. 解析为帧号或帧范围，调用 prepare() 收集位置
3. 对每架无人机，在收集的帧插入位置关键帧
4. 移除所有过渡约束（Copy Location Constraint）
```

### 3.3 辅助方法

| 方法 | 功能 |
|------|------|
| `prepare(frame)` | 跳转到指定帧，记录所有无人机位置 |
| `parse(text)` | 解析帧范围字符串，返回 (模式, 参数) |

## 5. 常见问题 FAQ

### Q1: 帧范围可以混合多种格式吗？

可以，用逗号分隔即可。例如 `"1,10-50,100-200:10"` 表示第1帧、第10-50帧逐帧、第100-200帧每10帧取一帧。

### Q2: 为什么要移除过渡约束？

过渡约束（Copy Location Constraint）在播放时动态计算位置，但导出时可能需要将实际位置固化为关键帧，以便离线查看或导出到其他系统。
