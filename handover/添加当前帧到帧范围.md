# SkybrushAddCurrentFrameToExportFrameDataOperator 交接文档

## 1. 概述

**类名**: `SkybrushAddCurrentFrameToExportFrameDataOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/hhang_operators.py`

**功能**: 将当前帧号追加到帧范围（frame_range）字符串中，方便快速构建导出帧列表。

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.add_current_frame_to_frame_range` |
| `bl_label` | Add current frame to frame range |
| `bl_options` | `REGISTER`, `UNDO` |

---

## 3. 核心逻辑

```
execute() → 追加当前帧到 frame_range
    ↓
┌─ 如果 frame_range 非空且末尾不是 '-': 先追加逗号 ','
└─ 追加当前帧号（字符串形式）
```

**示例**:
- 初始: `"1,10-50"` → 执行后: `"1,10-50,100"`
- 初始: `"1,10-50:"` → 执行后: `"1,10-50:100"`

---

## 4. 依赖关系

| 属性 | 用途 |
|------|------|
| `context.scene.skybrush.hhang.frame_range` | 帧范围字符串属性 |
