# 灯光特效偏移 Offset Light Effect 交接文档

## 1. 概述

**类名**: `SkybrushOffsetLightEffectOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/offset_light_effect.py`

**功能**: 批量偏移所有灯光特效的起始帧（`frame_start`）。

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.offset_light_effect` |
| `bl_label` | Offset light effect |
| `bl_description` | Offset the lighting effect start frame |
| `bl_options` | `REGISTER`, `UNDO`（支持撤销） |

### 2.1 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `frames` | IntProperty | 偏移帧数（正数=向后，负数=向前） |

---

## 3. 核心逻辑

```python
def execute(self, context):
    for entry in context.scene.skybrush.light_effects.entries:
        entry.frame_start += self.frames
    return {"FINISHED"}
```

**执行流程**:
1. 遍历灯光特效列表中的所有条目
2. 将每个条目的 `frame_start` 加上偏移量

**示例**:
- `frames = 10`: 所有特效起始帧 +10（推迟 10 帧）
- `frames = -5`: 所有特效起始帧 -5（提前 5 帧）

---
