# 灯光特效 — 函数类型 交接文档

## 1. 概述

灯光特效（Light Effect）系统支持三种特效类型：**Color Ramp**、**Image** 和 **Function**。本文档详细介绍 **Function（函数类型）** 的实现机制。

**Function 类型**允许用户通过自定义 Python 函数生成灯光颜色，支持时间、空间、无人机索引等参数，实现高度灵活的灯光效果。

## 3. 函数类型核心组件

### 3.1 颜色函数属性组

系统定义了两套函数属性组，用于存储自定义函数信息：

#### [`ColorFunctionProperties`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L360-L364) — 颜色函数

```python
class ColorFunctionProperties(ColorFunctionPropertiesBase, PropertyGroup):
    infunc = BoolProperty(name="In FUNCTION", default=True, options={"HIDDEN"})
```

用于 `LightEffect.color_function`，存储生成颜色的主函数。

#### [`ColorRampFunctionProperties`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L363-L364) — 输出函数

```python
class ColorRampFunctionProperties(ColorFunctionPropertiesBase, PropertyGroup):

```

用于 `LightEffect.output_function` 和 `output_function_y`，输出 X/Y 轴的索引值。

**`infunc` 标志**: 用于区分函数前缀：
- `infunc=True` → 函数名以 `FN_` 开头
- `infunc=False` → 函数名以 `CR_` 开头

## 4. 函数发现与加载

### 4.1 函数发现 [`get_color_function_names`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L203-L222)

```python
def get_color_function_names(self, context: Context) -> list[tuple[str, str, str]]:
    if self.path:
        module = load_module(self.path)
        mark = "FN" if self.infunc else "CR"
        dir_module = dir(module)
        _color_function_names = [
            name[3:]
            for name in dir_module
            if (
                isinstance(getattr(module, name), types.FunctionType)
                and name.startswith(mark)
                and f'ARGS_{name}' in dir_module
            )
        ]
    else:
        _color_function_names = []
    return [(name, name, "") for name in _color_function_names]
```

**函数命名规范**: 函数必须满足以下条件才会被发现：

1. 是 Python 函数类型（`types.FunctionType`）
2. 名称以 `FN_` 或 `CR_` 开头（取决于 `infunc`）
3. 存在对应的 `ARGS_函数名` 常量

**示例**:
```python
# 有效函数
def FN_rainbow(**kwargs): ...
ARGS_FN_rainbow = {"speed": 1.0, "phase": 0}

# 无效（缺少 ARGS_ 常量）
def FN_invalid(**kwargs): ...
```

### 4.2 参数自动解析 [`name_updated`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L241-L265)

```python
def name_updated(self, context: Context) -> None:
    if self.path and self.name and self.name != self.Name:
        symbol = f'ARGS_{"FN" if self.infunc else "CR"}_{self.name}'
        while self.args:
            self.args.remove(0)
        for key, value in getattr(load_module(self.path), symbol).items():
            arg = self.args.add()
            arg.prop_name = key
            if isinstance(value, int):
                arg.prop_type = "INT"
                arg.int_property = value
            elif isinstance(value, float):
                arg.prop_type = "FLOAT"
                arg.float_property = value
            elif isinstance(value, (list, tuple)):
                arg.prop_type = "ENUM"
                for item in value:
                    arg.enum_items.add().name = item
            elif value is None:
                arg.prop_type = "SEPARATOR"
```

**参数类型映射**:

| ARGS 值类型 | prop_type | 属性字段 |
|------------|-----------|----------|
| `int` | `INT` | `int_property` |
| `float` | `FLOAT` | `float_property` |
| `list/tuple` | `ENUM` | `enum_items` + `enum_property` |
| `None` | `SEPARATOR` | 无（分隔符） |

### 4.3 参数编码/解码

```python
def encode(args_dict):
    return ",".join([f"{key}={value}" for key, value in args_dict.items()])

def decode(kv_str):
    return {k: float(v) for k, v in [p.split("=") for p in kv_str.split(",")]} if kv_str else {}
```

用于将参数字典序列化为字符串格式，便于存储和传输。

## 6. 函数类型颜色生成

### 6.1 颜色函数引用 [`color_function_ref`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L1018-L1024)

```python
@property
def color_function_ref(self) -> Callable | None:
    if self.type != "FUNCTION" or not self.color_function:
        return None
    module = load_module(self.color_function.path)
    name = f'{"FN" if self.color_function.infunc else "CR"}_{self.color_function.name}'
    return getattr(module, name, None)
```

仅当特效类型为 `FUNCTION` 时返回可调用的函数引用。

### 6.2 颜色生成流程 [`apply_on_colors`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L894-L910)

当 `color_function_ref` 不为空时，调用自定义函数生成颜色：

```python
if color_function_ref is not None:
    try:
        new_color[:] = color_function_ref(
            frame=frame,
            time_fraction=time_fraction,
            drone_index=index,
            formation_index=(
                mapping[index]
                if mapping is not None and index < len(mapping)
                else None
            ),
            position=position,
            drone_count=num_positions,
            **fnkwargs(self.color_function, self.use_color_ramp),
        )
    except Exception as exc:
        raise RuntimeError("ERROR_COLOR_FUNCTION") from exc
```

### 6.3 函数参数详解

| 参数 | 类型 | 说明 |
|------|------|------|
| `frame` | int | 当前帧号 |
| `time_fraction` | float | 时间进度 [0, 1]，0=特效开始，1=特效结束 |
| `drone_index` | int | 无人机索引 [0, n-1] |
| `formation_index` | int/None | 编队中的索引（如有映射） |
| `position` | tuple(x, y, z) | 无人机当前位置 |
| `drone_count` | int | 无人机总数 |
| `args` | dict | 用户定义的参数（来自 `ARGS_` 常量） |
| `center` | tuple(x, y, z) | 编队中心位置 |
| `color_ramp` | ColorRamp | 关联的 Color Ramp（如 `use_color_ramp=True`） |
| `maxdist` | float | 编队最大半径 |
| `use_color_ramp` | bool | 是否使用 Color Ramp |

### 6.4 辅助参数构建 [`fnkwargs`](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L654-L661)

```python
def fnkwargs(function, use_color_ramp):
    return {
        "args": {arg.prop_name: arg.value for arg in function.args},
        "center": center,
        "color_ramp": self.color_ramp,
        "maxdist": maxdist,
        "use_color_ramp": use_color_ramp,
    }
```

## 7. CUSTOM 输出类型

除了主颜色函数，灯光特效还支持 **CUSTOM 输出类型**，使用函数计算 X/Y 轴的索引值。

### 7.1 [`output` 输出类型](file:///e:/hhang/studio-blender/src/modules/sbstudio/plugin/model/light_effects.py#L789-L811)

```python
elif output_type == "CUSTOM":
    module = load_module(output_function.path) if output_function.path else None
    if output_function.name:
        name = f'{"FN" if output_function.infunc else "CR"}_{output_function.name}'
        fn = getattr(module, name)
        outputs = [
            fn(
                frame=frame,
                time_fraction=time_fraction,
                drone_index=index,
                formation_index=...,
                position=positions[index],
                drone_count=num_positions,
                **fnkwargs(output_function, True),
            )
            for index in range(num_positions)
        ]
    else:
        common_output = 1.0
```

### 7.2 输出 X/Y 函数

| 属性 | 类型 | 说明 |
|------|------|------|
| `output_function` | ColorRampFunctionProperties | 输出 X 轴的自定义函数 |
| `output_function_y` | ColorRampFunctionProperties | 输出 Y 轴的自定义函数 |

**函数返回值**: 应为 [0, 1] 范围内的浮点数，用于索引 Color Ramp 或 Image。

## 8. 函数类型示例

### 8.1 颜色函数示例

```python
# 彩虹效果
def FN_rainbow(frame, time_fraction, drone_index, drone_count, position, args, **kwargs):
    import math
    speed = args.get("speed", 1.0)
    hue = (time_fraction * speed + drone_index / drone_count) % 1.0
    # HSV to RGB conversion
    h = hue * 6
    c = 1.0
    x = c * (1 - abs(h % 2 - 1))
    if h < 1: rgb = (c, x, 0)
    elif h < 2: rgb = (x, c, 0)
    # ... more cases
    return (*rgb, 1.0)

ARGS_FN_rainbow = {"speed": 1.0}
```

### 8.2 输出函数示例

```python
# 按高度输出
def CR_by_height(frame, position, drone_count, **kwargs):
    return min(max(position[2] / 50.0, 0.0), 1.0)

ARGS_CR_by_height = {}
```

### 9.2 Color Ramp 关联

当 `type == "FUNCTION"` 时，仍然可以使用 Color Ramp：

```python

def color_ramp(self) -> ColorRamp | None:
    return self.texture.color_ramp if self.type in ("COLOR_RAMP", "FUNCTION") else None
```

函数可以选择通过 `color_ramp` 参数获取 Color Ramp 并进行采样。

## 11. 调试与日志

### 11.1 错误处理

```python
try:
    new_color[:] = color_function_ref(...)
except Exception as exc:
    raise RuntimeError("ERROR_COLOR_FUNCTION") from exc
```

函数执行异常时会抛出 `RuntimeError("ERROR_COLOR_FUNCTION")`。

### 11.2 调试验证方法

1. 在 Python 文件中定义函数和 ARGS_ 常量
2. 在灯光特效面板选择 FUNCTION 类型
3. 加载文件并选择函数名
4. 调整参数值
5. 播放时间线观察颜色变化
6. 检查系统控制台的错误输出

### 11.3 常见问题排查

| 问题 | 可能原因 |
|------|----------|
| 函数列表为空 | 文件路径错误或函数不满足命名规范 |
| 参数不显示 | 缺少 `ARGS_函数名` 常量 |
| 颜色不变化 | 函数未正确返回 RGBA 颜色 |
| 报错 ERROR_COLOR_FUNCTION | 函数内部抛出异常 |

## 12. 常见问题 FAQ

### Q1: 函数文件放在哪里？

函数文件可以是：
1. Blender Text Editor 中的文本块
2. 外部 `.py` 文件（通过文件路径加载）

### Q2: 函数返回值格式是什么？

必须返回 RGBA 四元组 `(r, g, b, a)`，每个分量在 [0, 1] 范围内。

### Q3: `FN_` 和 `CR_` 前缀的区别是什么？

| 前缀 | 用途 | infunc |
|------|------|--------|
| `FN_` | 颜色函数，返回 RGBA 颜色 | True |
| `CR_` | 输出函数，返回 [0,1] 索引值 | False |

### Q4: 参数可动画是什么意思？

`options={'ANIMATABLE'}` 标记的参数可以在时间线上插入关键帧，实现参数随时间变化。

### Q5: 如何在函数中使用 Color Ramp？

设置 `use_color_ramp=True`，函数可以通过 `color_ramp.evaluate(ratio)` 采样颜色。

### Q6: CUSTOM 输出类型何时使用？

当内置的输出类型（FIRST_COLOR、LAST_COLOR、GRADIENT_* 等）无法满足需求时，使用 CUSTOM 类型自定义 X/Y 轴的索引计算逻辑。
