1. 概述

类名: ValidateLightsOperator

文件路径: src/modules/sbstudio/plugin/operators/validate_lights.py

功能: Blender Operator，用于在指定帧范围内验证无人机灯光颜色是否超过亮度阈值。验证在本地执行，结果存储到 Blender 场景属性中，通过 Safety Check 面板以 UI 形式展示。

3. 核心验证逻辑

3.1 执行流程

invoke() → 弹出参数对话框
    ↓
execute() → 开始验证
    ↓
1. 获取无人机列表和帧范围
2. 初始化结果列表、历史字典、帧缓冲区
3. 逐帧遍历 [start_frame, end_frame]:
   - 获取每架无人机的灯光颜色（R/G/B 三通道 0~255 值）
   - 将当前帧数据加入滑动窗口缓冲区
   - 当缓冲区满（达到 interval 帧）时，检查每架无人机是否超标
4. 将结果存储到 bpy.types.Scene.validate_lights_result

3.2 颜色转换

linear_2_gamma - 线性转 Gamma 校正

将线性色彩空间值转换为 Gamma 校正后的值：

def linear_2_gamma(value: float) -> float:
    if value <= 0.0:
        return 0.0
    elif value <= 0.0031308:
        return 12.92 * value
    elif value < 1.0:
        return 1.055 * pow(value, 0.4166667) - 0.055
    else:
        return pow(value, 0.45454545)

使用 sRGB 标准的 Gamma 校正曲线，分段处理低亮度（线性区）和高亮度（幂函数区）。

get_int_255_color - 获取 0~255 颜色值

def get_int_255_color(drone) -> list[int]:
    return [max(0, min(255, int(linear_2_gamma(c) * 255 + 0.5))) for c in get_color_of_drone(drone)[:3]]

从无人机获取 RGB 颜色 → Gamma 校正 → 缩放到 0~255 → 四舍五入取整 → 截断到有效范围。

3.3 超标检测逻辑

滑动窗口机制

使用 collections.deque(maxlen=interval) 作为滑动窗口缓冲区：

  • frame_buffer: 存储最近 interval 帧的灯光颜色数组
  • frame_indices: 存储对应的帧号

超标判定条件

一架无人机在滑动窗口内被判定为违规需同时满足：

  1. 通道超标: R/G/B 三个通道全部超过对应阈值（np.all(frame_lights[idx] > limit)）
  2. 占比达标: 超标帧数 ≥ ceil(interval × percentage / 100)

例如：interval=20, percentage=50 时，需要至少 10 帧超标才记录违规。

结果记录

result = [
    (drone_index, (peak_frame, peak_value)),
    ...
]
  • peak_frame: 超标期间 RGB 最大值的帧号
  • peak_value: 超标期间 RGB 三通道的最大值（浮点数）

历史记录机制: 使用 history 字典追踪持续违规的无人机，仅当出现新的峰值时才更新记录，违规结束时从字典中移除。

选择列表中的某一项会自动跳转到对应帧并高亮相关无人机。

9. 常见问题 FAQ

Q1: 为什么需要三个通道都超标才记录违规？

因为无人机 LED 灯是 RGB 三色独立控制的，只有当三个通道同时超过阈值时，整体亮度才会超过安全上限。如果仅部分通道超标，实际视觉效果可能仍在可接受范围内。

Q2: interval 和 percentage 参数如何配合使用？

  • interval: 定义滑动窗口大小，即统计的帧数范围
  • percentage: 定义窗口内超标帧的最小占比

例如：

  • interval=20, percentage=50: 20 帧内至少 10 帧超标才记录
  • interval=10, percentage=80: 10 帧内至少 8 帧超标才记录

增大 percentage 可以降低偶发超标的误报，增大 interval 可以更平滑地检测持续超标。

Q3: Gamma 校正的作用是什么？

Blender 内部使用线性色彩空间存储颜色值，但人眼感知亮度是非线性的。Gamma 校正将线性值转换为符合人眼感知的非线性值，使验证结果更贴近实际视觉效果。

Q4: 验证过程很慢怎么办？

  • 减少验证的帧范围
  • 减少无人机数量（使用 selected_only 仅验证选中的无人机）
  • 增大 interval 参数可以减少检查频率（但会影响检测精度）
