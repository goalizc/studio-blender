1. 概述

文件路径: src/modules/sbstudio/plugin/model/light_effects.py

灯光特效系统中需要判断无人机是否在某个网格物体内部（target = "INSIDE_MESH"），文件包含两个实现：

函数行数说明

当前系统使用 test_containment（见 第1329行）。

2. test_containment_skybrush 原始版本

2.1 代码

def test_containment_skybrush(bvh_tree: BVHTree | None, point: Coordinate3D) -> bool:
    """Given a point and a BVH-tree, tests whether the point is _probably_
    within the mesh represented by the BVH-tree.

    This is done by casting three rays in the X, Y and Z directions. The point
    is assumed to be within the mesh if all three rays hit the mesh.

    Returns True if the BVH-tree is missing.
    """
    if not bvh_tree:
        return True

    for axis in CONTAINMENT_TEST_AXES:
        _, _, _, dist = bvh_tree.ray_cast(point, axis)
        if dist is None or dist == -1:
            return False

    return True

2.2 算法原理

沿 X、Y、Z 三个方向各发射一条射线，如果三条射线都命中网格，则认为点在内部。

2.3 存在问题

问题说明
误判凹形物体射线穿过凹形物体时可能命中多个面，但算法只检查是否命中，不统计次数
误判甜甜圈形状点在甜甜圈孔洞中时，三个方向都可能命中外侧网格，但点实际在外部
误判薄壁物体点在薄壁物体外部但靠近表面时，射线可能恰好命中，导致误判为内部
文档注明 "probably"原作者也意识到这是近似检测，非精确判断

2.4 误判示例

    ┌─────┐
    │  ·  │  ← 点在空心立方体内部，三方向都命中 → 正确判定为内部
    └─────┘

    ┌─┐ ┌─┐
    │ · │    ← 点在两个分离立方体之间，
    └─┘ └─┘    X方向命中两侧 → 误判为内部

    ○          ← 点在甜甜圈孔洞中，
                 X/Y方向命中外环 → 误判为内部

3. test_containment 修复版本

3.1 代码

def test_containment(bvh_tree: Optional[BVHTree], point: Coordinate3D) -> bool:
    # 定义射线方向（任意方向都可以，这里选择X轴正方向）
    direction = Vector((1, 0, 0))

    # 进行射线投射
    hit, normal, index, distance = bvh_tree.ray_cast(point, direction)

    # 如果没有命中任何面，点在物体外部
    if hit is None:
        return False

    # 计算射线与网格的交点数量
    intersections = 0
    max_distance = 10000.0  # 设定一个足够大的最大距离

    current_point = point
    current_distance = 0.0

    while True:
        # 从当前点继续发射射线
        hit, normal, index, dist = bvh_tree.ray_cast(current_point, direction)

        # 如果没有更多交点，退出循环
        if hit is None:
            break

        # 累加交点数量
        intersections += 1

        # 更新当前点位置（稍微向前移动以避免浮点数精度问题）
        current_distance += dist + 0.01
        current_point = Vector(point) + direction * current_distance

        # 防止无限循环
        if current_distance > max_distance:
            break

    # 如果交点数量为奇数，点在内部；偶数则在外部
    return(intersections % 2 == 1)

3.2 算法原理：射线法 (Ray Casting)

基于奇偶规则 (Odd-Even Rule)：

从点 P 沿任意方向发射一条射线，统计射线与网格的交点数量： - 奇数 → 点在内部 - 偶数 → 点在外部

数学原理: 每次射线穿过网格表面，点在内部/外部状态就切换一次。从外部开始（状态 = 外部），穿过奇数次后到达内部，穿过偶数次后回到外部。

3.3 执行流程

输入: BVH树, 检测点
    ↓
1. 沿 X+ 方向发射第一条射线
    ↓
2. 未命中 → 点在外部，返回 False
    ↓
3. 命中 → 进入循环统计交点
    ↓
4. 累加交点数量 (intersections += 1)
    ↓
5. 前进到交点之后 (dist + 0.01)
    ↓
6. 继续发射射线
    ↓
7. 无更多交点 或 超过最大距离 → 退出循环
    ↓
8. 返回 intersections % 2 == 1

3.4 关键设计

避免浮点数精度问题

current_distance += dist + 0.01
current_point = Vector(point) + direction * current_distance

每次前进时额外偏移 0.01，避免射线起点恰好落在网格表面上导致重复命中同一面。

防止无限循环

max_distance = 10000.0
if current_distance > max_distance:
    break

对于复杂的自相交网格或螺旋结构，设置最大距离限制。

方向选择

direction = Vector((1, 0, 0))  # X轴正方向

选择任意方向均可，X+ 方向简单且通常有效。特殊情况下（射线恰好平行于某个面）可通过 0.01 偏移规避。

    if self.target == "INSIDE_MESH":
        bvh_tree = self._get_bvh_tree_from_mesh()
        func = partial(test_containment, bvh_tree)  # ← 使用修复版本

        func = partial(test_is_in_front_of, plane)

        func = None

6. 算法限制

6.1 已知限制

限制说明
要求封闭网格算法假设网格是封闭的，开口网格会导致检测不准确
自相交网格网格自相交时，交点计数可能不准确
点在表面上射线起点恰好落在表面上时，结果不确定
单方向射线仅沿 X+ 方向，如果网格在该方向有特殊情况（如所有面平行于 X 轴），可能漏检

6.2 改进建议

如需更高精度，可考虑：

  1. 多方向射线: 沿多个方向发射射线，取多数投票结果
  2. 符号距离场 (SDF): 预计算网格的符号距离场，O(1) 查询
  3. winding number 算法: 更精确的点包含检测，支持非流形网格

9. 常见问题 FAQ

Q1: 为什么选择 X+ 方向而不是其他方向？

任意方向在数学上都是等效的。X+ 方向是最简单的选择。0.01 的额外偏移可以处理射线恰好平行于网格面的情况。

Q2: 0.01 的偏移量是怎么确定的？

这是一个经验值，需要大于浮点数精度误差（约 1e-6），但小于网格的最小特征尺寸。对于大多数无人机编队场景（尺度 1-1000m），0.01 是一个合理的选择。

Q3: 如果网格有开口怎么办？

开口网格会导致射线逃逸，从而错误地将内部点判定为外部。这种情况下建议：

  1. 使用封闭网格
  2. 或改用 FRONT_SIDE 模式（基于平面检测）

Q4: 为什么原始版本要用三个方向？

原作者试图通过多方向检测提高准确性，但方法本身有根本缺陷：即使三个方向都命中，也不能证明点在内部（如甜甜圈孔洞的情况）。修复版本通过统计交点数量从根本上解决了这个问题。
