1. 概述

文件路径: src/modules/sbstudio/api/algorithm.py

功能: 这是编队过渡的核心算法，负责将起飞位置与目标编队位置进行最优匹配，使得所有无人机沿直线飞行时的最小间距最大化，从而避免碰撞。算法使用匈牙利算法初始化 + 模拟退火局部搜索的组合优化策略。

3. 算法详解

3.1 trajectory_min_distance_vectorized — 轨迹最小距离计算

def trajectory_min_distance_vectorized(a1, b1, a2, b2):
    u, v = a1 - a2, (b1 - a1) - (b2 - a2)
    n, d = np.einsum('nd,nd->n', u, v), np.einsum('nd,nd->n', v, v)
    return np.linalg.norm(u + np.clip(-n / (d + 1e-10), 0.0, 1.0)[:, None] * v, axis=1)

数学原理: 计算两条线段 a1→b1 和 a2→b2 之间的最短距离。

公式推导:

  • u = a1 - a2: 起点差向量
  • v = (b1-a1) - (b2-a2): 方向差向量
  • 两条线段上任意两点可表示为: P(t) = a1 + t·(b1-a1), Q(t) = a2 + t·(b2-a2)
  • 距离函数: D(t) = ||P(t) - Q(t)|| = ||u + t·v||
  • 最小值在 t* = -(u·v) / (v·v) 处取得（投影法）
  • 由于 t ∈ [0,1]，使用 clip(t*, 0, 1) 约束范围

向量化: 一次计算 N 条轨迹对的距离，避免循环。

3.2 max_min_distance_matcher_internal — 核心优化算法

这是整个算法最复杂的部分，结合了多种优化策略。

接受准则（模拟退火）:

  • 必接受: new_min > current_min（改进解）
  • 概率接受: random() < acceptance_rate（劣解，避免局部最优）
  • 更新全局最优: 当找到更好的最小距离时，重置探索状态

3.2.3 generate_neighbor — 邻居生成

def generate_neighbor(i, j):
    new_dist_matrix = dist_matrix.copy()
    new_perm = perm.copy()
    new_perm[i], new_perm[j] = new_perm[j], new_perm[i]

    k_indices = np.arange(N)
    a2_k = A[k_indices]
    b2_k = B[new_perm[k_indices]]
    a1_i = np.tile(A[i], (N, 1))
    b1_i = np.tile(B[new_perm[i]], (N, 1))
    distances_i = trajectory_min_distance_vectorized(a1_i, b1_i, a2_k, b2_k)
    a1_j = np.tile(A[j], (N, 1))
    b1_j = np.tile(B[new_perm[j]], (N, 1))
    distances_j = trajectory_min_distance_vectorized(a1_j, b1_j, a2_k, b2_k)

    for k in range(N):
        if k != i: new_dist_matrix[(k, i) if k < i else(i, k)] = distances_i[k]
        if k != j: new_dist_matrix[(k, j) if k < j else(j, k)] = distances_j[k]

    return new_dist_matrix, new_perm, np.min(new_dist_matrix)

算法:

  1. 交换 perm[i] 和 perm[j]（交换两个无人机的目标）
  2. 增量更新距离矩阵：只重新计算与 i 和 j 相关的轨迹对，避免 O(N²) 全量计算
  3. 返回更新后的距离矩阵和新排列

3.3 max_min_distance_matcher — 公开接口

def max_min_distance_matcher(A, B, *, threshold=2.5):
    if len(A) == len(B):
        return max_min_distance_matcher_internal(A, B, threshold=threshold)
    base = linear_sum_assignment(distance_matrix(A, B) ** 3)[1]
    perm, dist = max_min_distance_matcher_internal(A, B[base], threshold=threshold)
    return base[perm].tolist(), dist

数量不等处理:

  1. 当 A 和 B 数量不同时，先用匈牙利算法找到 B 的最佳子集 base
  2. 对 A 和 B[base] 调用核心算法
  3. 映射回原始索引 base[perm]

4. 返回值

5.3 SkybrushStudioAPI.plan_transition [base.py:807-830]

def plan_transition(self, source, target, *, max_velocity_xy, max_velocity_z, ...):
    threshold = bpy.context.scene.skybrush.safety_check.proximity_warning_threshold + 0.5
    perm, (xydist, zdowndist, zupdist) = max_min_distance_matcher(target, source, threshold=threshold)
    zdowndist, zupdist = -min(0, -zdowndist), max(0, -zupdist)
    duration = xydist * 1.5 / max_velocity_xy
    duration = max(duration, zdowndist * 1.5 / max_velocity_z)
    duration = max(duration, zupdist * 1.5 / (max_velocity_z_up or max_velocity_z))
    return TransitionPlan(start_times=[0]*len(target), durations=[duration]*len(target), mapping=perm, clearance=None)

持续时间计算: 根据匹配结果的最大距离和速度约束，计算所有无人机完成过渡所需的时间。取水平、下降、上升三个方向的最大值。

8. 算法特点

8.1 优势

特点说明
增量更新generate_neighbor 只更新 O(N) 距离，而非 O(N²) 全量计算
模拟退火接受劣解避免陷入局部最优
自适应接受率根据当前解质量动态调整探索/利用平衡
匈牙利初始化提供良好的初始解，加速收敛
三重邻居策略深度优先 + 广度搜索结合，平衡探索效率

8.2 局限性

局限说明
仅直线轨迹算法只考虑直线过渡，不支持曲线轨迹
无时间调度所有无人机同时开始和结束过渡，不支持错开起飞
O(N²) 内存距离矩阵占用 O(N²) 内存，大规模时可能成为瓶颈
确定性随机固定随机种子 20181213，结果可复现但无法多次采样

9. 常见问题 FAQ

Q1: 为什么使用 distance_matrix(A, B) ** 3 作为匈牙利算法的代价？

三次方放大远距离的差异，使得算法更倾向于匹配距离近的点对。如果直接用距离（一次方），近距离点的优势不够明显，可能导致整体匹配不佳。

Q2: 接受率是如何计算的？

使用 np.interp(Min, critical, weights) 进行线性插值：

Min < 0.8T  →  接受率 = 0.8
Min = 0.9T  →  接受率 ≈ 0.65（插值）
Min = 0.95T →  接受率 = 0.5
Min = T     →  接受率 = 0.2

Q3: 为什么固定随机种子 20181213？

确保结果可复现。相同的输入总是产生相同的匹配方案，便于调试和版本控制。

Q4: closest_B 的作用是什么？

预计算 B 中每个点的最近邻排序。当交换 perm[i] 和 perm[j] 无法改善时，算法尝试将 i 分配到 B[perm[j]] 的最近邻，加速搜索过程。

Q5: 终止条件有哪些？

  1. Min >= threshold: 达到目标安全距离，最优情况
  2. k >= n 且 e >= 9: 探索步数耗尽，局部搜索完成
  3. 无法找到更好的邻居，接受率趋近于 0
