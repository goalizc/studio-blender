# SkybrushCalculateGroupTakeoffOperator 交接文档

## 1. 概述

**类名**: `SkybrushCalculateGroupTakeoffOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/hhang_operators.py`

**功能**: 计算分组起飞路径。按空间距离将无人机分组，每组按固定间距依次错开起飞，插入关键帧形成分层起飞动画。支持 `dryrun` 模式仅创建编队集合而不插入关键帧。

---

## 2. 类属性

| 属性 | 值 |

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `distance` | FloatProperty | 3m | 1~50m | 同层无人机最小间距，用于分组判定 |

| `min_height` | FloatProperty | 50m | 20~1000m | 底层最低高度 |

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|

| `offset_y` | FloatProperty | 0 | -100~100m | Y 轴偏移距离 |
| `zoom_height` | FloatProperty | 30m | 10~1000m | 开始缩放的高度 |
| `zoom_ratio` | FloatProperty | 1 | 0~1000 | 最大缩放比例（1 表示不缩放） |

#### 速度参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `velocity` | FloatProperty | 3 m/s | - | 上升速度 |

| `dryrun` | BoolProperty (HIDDEN) | False | - | 试运行模式，仅生成编队不插关键帧 |

## 3. 核心逻辑

### 3.1 执行流程

```
invoke() → 弹出参数对话框
    ↓
execute() → 开始执行
    ↓
1. 参数校验: 修正 zoom_height、layer_height、velocity 边界值
2. 跳转到帧1，获取所有无人机位置
3. 按 X×10000+Y 排序无人机（行优先顺序）
4. 贪婪分组: 每次选一架无人机作为起点，迭代添加满足间距要求的无人机
5. 计算各时间帧: f1(悬停), f2(悬停结束), f3(缩放开始), f4(到达目标)
6. 逐组插入关键帧:
   - T1: 起始位置（LINEAR）
   - T2: 上升到 stay_altitude（LINEAR）
   - T3: 悬停等待（LINEAR）
   - T4: 缩放到 zoom_height（BEZIER/BEZIER/LINEAR）
   - T5: 到达目标高度（LINEAR）
7. dryrun 模式下创建 "group takeoff" 编队集合
```

### 3.2 参数校验

```python
self.zoom_height = max(self.stay_altitude, min(self.zoom_height, self.min_height))
if self.layer_height < self.stay_altitude:
    self.layer_height = self.stay_altitude
if self.velocity < 1:
    self.velocity = 1
```

| 校验项 | 规则 |
|--------|------|
| zoom_height | 必须在 [stay_altitude, min_height] 范围内 |
| layer_height | 不能小于 stay_altitude |
| velocity | 不能小于 1 m/s |

### 3.3 分组算法

```python
def calc(a, b):
    # 计算组 a 与候选无人机 b 中每个成员的最小距离
    a = np.array([get_position_of_object(obj) for obj in a]).round(decimals=3)
    b = np.array([get_position_of_object(obj) for obj in b]).round(decimals=3)
    c = b[:,None,:] - a                                    # 距离差向量
    d = np.min(np.sqrt(np.sum(c * c, axis=-1)), axis=1)    # 最小距离
    for i in np.argsort(d):
        if d[i] >= self.distance: return i                  # 返回满足间距的第一个
    return None

drones.sort(key=lambda a: a.location.x * 10000 + a.location.y)  # 行优先排序
groups = []
while len(drones):
    group = [drones[0]]; del(drones[0])
    while len(drones):
        i = calc(group, drones)
        if i is None: break
        group.append(drones[i]); del(drones[i])
    groups.append(group)
```

**算法说明**:
1. 按 X×10000+Y 排序，确保行优先处理顺序
2. 贪婪策略：每轮从剩余无人机中选一个起点
3. 迭代添加：每次选与当前组中所有成员距离都 ≥ `distance` 的无人机
4. 当无法添加更多无人机时，结束当前组，开始下一轮

### 3.4 时间线计算

```python
f1 = self.stay_altitude * FPS                                    # 上升到悬停高度的帧数
f2 = f1 + self.stay_time * FPS                                   # 悬停结束帧（相对于组起始帧）
f3 = f2 + ceil((self.zoom_height - self.stay_altitude) * FPS / velocity)  # 缩放开始帧
f4 = f2 + (height - self.stay_altitude) / velocity * FPS         # 到达目标高度帧
```

| 阶段 | 相对帧 | 动作 | 插值方式 |
|------|--------|------|----------|
| T1 | `fr` | 记录起始位置 | LINEAR |
| T2 | `fr + f1` | 上升到 `stay_altitude` | LINEAR |
| T3 | `fr + f2` | 悬停等待 RTK 连接 | LINEAR |
| T4 | `fr + f3` | 上升到 `zoom_height` 并缩放 XY | BEZIER/BEZIER/LINEAR |
| T5 | `fr + f4` | 到达目标高度 `height` | LINEAR |

其中 `fr` 为当前组的起始帧，每组的 `fr` 递增：
```python
inc = ((self.layer_height - self.stay_altitude) / self.velocity + self.stay_altitude + self.stay_time) * FPS
f, fr = 1, 1  # 初始值
for group in groups:
    fr = f; f += inc
```

### 3.5 关键帧插入

```python
def keyframe_insert(self, drone, interpolation, frame):
    if not self.dryrun:
        drone.keyframe_insert(data_path="location", frame=frame)
        if type(interpolation) not in (list, tuple):
            interpolation = [interpolation] * 3
        self.set_interpolation(drone, frame, 0, interpolation[0])
        self.set_interpolation(drone, frame, 1, interpolation[1])
        self.set_interpolation(drone, frame, 2, interpolation[2])

def set_interpolation(self, drone, frame, index, interpolation):
    kp = drone.animation_data.action.fcurves.find("location", index=index).keyframe_points
    for k in [k for k in kp if k.co[0] == frame]:
        k.interpolation = interpolation
```

**插值方式**: 对 X/Y/Z 三个轴分别设置，`("BEZIER", "BEZIER", "LINEAR")` 表示 XY 用贝塞尔曲线（平滑），Z 用线性（匀速）。

### 3.6 缩放计算

当 `zoom_ratio ≠ 1` 时：
```python
drone.location[2] = self.zoom_height
self.keyframe_insert(drone, ("BEZIER", "BEZIER", "LINEAR"), math.ceil(fr + f3))
drone.location[0] = (drone.location[0] - center[0]) * self.zoom_ratio + center[0]
drone.location[1] = (drone.location[1] - center[1]) * self.zoom_ratio + center[1]
drone.location[0] += self.offset_x
drone.location[1] += self.offset_y
drone.location[2]  = height
```

先上升到 `zoom_height`，然后按 `zoom_ratio` 收缩编队范围（以中心点为基准），再施加偏移，最后到达目标高度。

## 8. 常见问题 FAQ

### Q1: stay_altitude 和 stay_time 的作用是什么？

RTK 系统连接需要时间。无人机先上升到 `stay_altitude`（默认 5m）悬停，等待 `stay_time`（默认 5s）完成 RTK 定位后再继续上升。这是实际飞行操作的标准流程。

### Q2: dryrun 模式何时使用？

`dryrun=True` 通常由 `SkybrushRecalculateGroupTakeoffOperator` 内部调用，用于预计算分组信息而不产生关键帧。单独使用时可以预览分组结果。

### Q3: velocity 为什么不能小于 1？

速度过小会导致计算出的帧数过大，关键帧间隔过长，动画不流畅。强制最小值 1 m/s 保证合理的起飞速度。

### Q4: 分组顺序如何确定？

按 X×10000+Y 的行优先顺序排序。这意味着无人机按行（Y 轴）为主、列（X 轴）为次的顺序被分配到不同组中。
