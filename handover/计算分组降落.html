计算分组降落

按高度分层依次错开降落的自动化安全路径生成算法

1. 概述

类名: SkybrushCalculateGroupLandOperator

文件路径: src/modules/sbstudio/plugin/operators/hhang_operators.py

功能: 计算分组降落路径。按高度分层将无人机分组，每组依次错开降落，形成分层降落动画。通过故事板系统生成过渡轨迹，然后逐组插入降落关键帧。

3. 核心逻辑

3.1 执行流程

invoke() → 弹出参数对话框
    ↓
execute() → 开始执行
    ↓
1. 参数校验: 修正 layer_height 和 zoom_height 边界值
2. 跳转到帧1，获取无人机位置
3. 贪婪分组: 按当前高度从低到高逐层分组
4. 创建 "group land" 编队（缩放后的位置）
5. 通过故事板系统添加编队条目并重新计算过渡
6. 调用 replace_copy_location_constraint 替换约束为关键帧
7. 在过渡结束后+1帧记录所有无人机当前位置
8. 逐组插入降落关键帧:
   - 当前位置（BEZIER/BEZIER/LINEAR）
   - 缩放到 zoom_height
   - 下降到 landing_height
   - 降落到地面 z=0

3.2 参数校验

if self.layer_height > self.landing_height:
    self.layer_height = self.landing_height
self.zoom_height = max(self.landing_height, min(self.zoom_height, self.min_height))
校验项规则
layer_height不能大于 landing_height
zoom_height必须在 [landing_height, min_height] 范围内

3.3 分组算法

drones.sort(key=lambda a: a.location.x * 10000 + a.location.y)  # 不排序，按当前位置
height = self.min_height
while len(drones):
    group = [drones[0]]; del(drones[0])
    while len(drones):
        i = calc(group, drones)
        if i is None: break
        group.append(drones[i]); del(drones[i])
    points += [(drone.location[0], drone.location[1], height) for drone in group]
    height += self.layer_height

与起飞分组的区别：降落分组按高度分层，而非按空间距离分组。最低层的无人机最先降落。

3.4 故事板过渡生成

points = (np.array(points) - center) * (self.zoom_ratio, self.zoom_ratio, 1) + center
create_formation("group land", points.tolist())
bpy.data.scenes["Scene"].skybrush.formations.selected = bpy.data.collections["group land"]
skybrush.append_formation_to_storyboard()
skybrush.recalculate_transitions(scope='TO_SELECTED')
  1. 将分层位置按 zoom_ratio 缩放
  2. 创建 "group land" 编队
  3. 添加到故事板并重新计算过渡轨迹
  4. 通过 replace_copy_location_constraint 将过渡约束固化为关键帧

3.5 降落关键帧时间线

fps, frame = context.scene.render.fps, context.scene.frame_current
landframes = self.landing_height * fps                    # 从 landing_height 到地面的帧数
step = self.layer_height / 2 * fps                        # 每组之间的时间间隔
阶段时间点动作插值方式
T1frame记录当前位置BEZIER/BEZIER/LINEAR
T2frame + zoom缩放到 zoom_heightLINEAR
T3frame + landing下降到 landing_heightLINEAR
T4frame + landing + landframes降落到地面（z=0）LINEAR

其中：

  • zoom = (height - zoom_height) / 2 × FPS — 缩放到缩放高度的帧数
  • landing = (height - landing_height) / 2 × FPS — 下降到降落高度的帧数
  • 每组之间间隔 step 帧

3.6 降落关键帧插入

while len(drones):
    group = [drone for drone in drones if abs(get_position_of_object(drone)[2] - height) < 0.1]
    if not group:
        self.report({"ERROR"}, "无法获取正确高度，分组时出现错误")
        return {"CANCELLED"}
    zoom = (height - self.zoom_height) / 2 * fps
    landing = (height - self.landing_height) / 2 * fps
    for drone in group:
        keyframe_insert(drone, frame, ("BEZIER", "BEZIER", "LINEAR"))
        point = (np.array(drone.location) - center) / self.zoom_ratio + center
        drone.location = mathutils.Vector((point[0], point[1], self.zoom_height))
        keyframe_insert(drone, frame + zoom)
        drone.location[2] = self.landing_height
        keyframe_insert(drone, frame + landing)
        drone.location[2] = 0
        keyframe_insert(drone, frame + landing + landframes)
    height += self.layer_height
    frame  += step
    drones  = [drone for drone in drones if drone not in group]

算法说明:

  1. 从最低层开始，按高度提取每组的无人机
  2. 对组内每架无人机插入4个关键帧
  3. 缩放位置以编队中心为基准
  4. 处理完一组后，高度递增，时间递增 step 帧
  5. 从无人机列表中移除已处理的组

3.7 辅助方法

def set_interpolation(drone, frame, index, interpolation):
    kp = drone.animation_data.action.fcurves.find("location", index=index).keyframe_points
    for k in [k for k in kp if k.co[0] == frame]:
        k.interpolation = interpolation

def keyframe_insert(drone, frame, interpolation="LINEAR"):
    drone.keyframe_insert(data_path="location", frame=frame)
    if type(interpolation) not in(list, tuple):
        interpolation = [interpolation] * 3
    set_interpolation(drone, frame, 0, interpolation[0])
    set_interpolation(drone, frame, 1, interpolation[1])
    set_interpolation(drone, frame, 2, interpolation[2])

插值方式: 与起飞类似，降落时第一个关键帧使用 ("BEZIER", "BEZIER", "LINEAR")，其余使用 LINEAR。

8. 常见问题 FAQ

Q1: layer_height 为什么不能大于 landing_height？

降落时，每组之间的高度差（layer_height）必须小于或等于开始降落的高度（landing_height），否则上层无人机会在还没下降到 landing_height 时就已经接触地面。

Q2: zoom_ratio 为 0 时会发生什么？

zoom_ratio = 0 时，所有无人机的 XY 位置会被压缩到编队中心点。这适用于需要紧凑降落的场景，但可能导致无人机在缩放阶段过于接近。

Q3: 为什么要先调用 replace_copy_location_constraint？

故事板生成的过渡轨迹使用 Copy Location 约束动态计算位置。降落关键帧需要基于实际位置插入，因此必须先将约束固化为显式关键帧。

Q4: 降落分组与起飞分组有什么区别？

对比项起飞分组降落分组
分组依据空间距离（贪婪算法）高度分层
排序方式X×10000+Y 行优先按当前 Z 高度
时间顺序高层后起飞低层先降落
