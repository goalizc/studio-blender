# RedistributionTakeoffGridOperator 交接文档

## 1. 概述

**类名**: `RedistributionTakeoffGridOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/redistribution_takeoff_grid.py`

**功能**: 重新分配无人机的起飞网格位置。支持两种模式：从文件导入位置数据，或按行列自动生成网格。

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.redistribution_takeoff_grid` |
| `bl_label` | Redistribution Takeoff Grid |
| `bl_options` | `REGISTER`, `UNDO`（支持撤销） |

### 2.1 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `use_import` | BoolProperty | False | 是否从文件导入位置数据 |
| `rows` | IntProperty | 10 | 网格行数（自动生成模式） |
| `spacing` | FloatProperty | 3m | 网格间距（自动生成模式） |

---

## 3. 核心逻辑

### 3.1 执行流程

```
invoke() → 弹出对话框，选择导入模式或自动生成模式
    ↓
execute() → 执行重分配
    ↓
┌─ 导入模式:
│  1. 读取 JSON 文件中的位置数组
│  2. 验证位置数量与无人机数量匹配
│  3. 将每个位置分配给对应无人机（按 Drone 编号排序）
│
└─ 自动生成模式:
   1. 按行优先顺序计算网格坐标: x = i // rows, y = i % rows
   2. 分配位置: (x * spacing, y * spacing, 0)
    ↓
在帧1插入关键帧，并跳转到帧1
```

### 3.2 文件格式（导入模式）

JSON 数组格式，每个元素为 `[x, y]` 坐标：

```json
[
  [0.0, 0.0],
  [3.0, 0.0],
  [0.0, 3.0],
  ...
]
```

位置数量必须与场景中无人机数量一致。

### 3.3 无人机排序

```python
sorted(drones, key=lambda a: int(a.name[6:]))
```

按 `Drone N` 中的数字 N 升序排列。
