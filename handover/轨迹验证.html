1. 概述

类名: ValidateTrajectoriesOperator

文件路径: src/modules/sbstudio/plugin/operators/validate_trajectories.py

功能: Blender Operator，用于在指定帧范围内逐帧验证无人机飞行轨迹是否违反安全约束。验证在本地执行，结果存储到 Blender 场景属性中，通过 Safety Check 面板以 UI 形式展示。

3. 核心验证逻辑

3.1 执行流程

invoke() → 弹出参数对话框
    ↓
execute() → 开始验证
    ↓
1. 获取无人机列表和帧范围
2. 计算最大倾斜加速度: max_tilt_acceleration = 9.8 * tan(max_tilt_angle)
3. 初始化所有历史记录字典和结果列表
4. 逐帧遍历 [start_frame, end_frame]:
   - 获取每架无人机的位置
   - 检查距离约束 (check_distance)
   - 检查速度/加速度/角度约束 (check_velocity)
5. 将结果存储到 bpy.types.Scene.validate_trajectories_result

3.2 检查项详解

check_distance - 距离检查

算法: 使用 NumPy 广播计算所有无人机对之间的距离矩阵。

dist = tril + np.triu(np.sqrt(((points[:, None, :] - points) ** 2).sum(-1)))
  • tril: 下三角矩阵填充999，用于排除对角线和下三角，只保留上三角部分
  • 避免重复计算 A↔B 和 B↔A

特殊逻辑: 如果 proximity_warning_target == "ABOVE_MIN_NAV_ALT"，只检查高于最小导航高度的无人机对。

结果格式: distance_result = [((drone_i, drone_j), (frame, min_distance)), ...]

check_velocity - 速度/加速度/角度检查

水平速度 Vxy

Vxy = sqrt(Δx² + Δy²) × FPS    # 单位: m/s

水平加速度 Axy

Axy = |Vxy_current - Vxy_previous| × FPS    # 单位: m/s²

重要: 必须乘以 FPS 才能得到正确的加速度单位 (m/s²)。 因为速度差除以时间间隔 = 速度差 × FPS。

垂直速度 Vz

Vz = Δz × FPS    # 单位: m/s

垂直加速度 Az

Az = |Vz_current - Vz_previous| × FPS    # 单位: m/s²

转弯角度 angle

算法: 计算相邻两帧速度向量的夹角，判断转弯是否超过倾斜加速度限制。

max_tilt_acceleration = g × tan(max_tilt_angle)    # g = 9.8 m/s²
cosθ = (A·B) / (|A| × |B|)
θ = arccos(cosθ)
angle_metric = sqrt(max_tilt_acceleration × velocity / θ)

物理意义: 当无人机转弯时，向心加速度不能超过倾斜加速度限制。

阈值: 连续 5 帧超过阈值才记录为违规（去抖动逻辑）。

3.3 历史记录机制

每个检查项维护一个 history 字典，用于追踪违规的持续区间和峰值。

数据结构:

history = {
    drone_index: (first_violation_frame, peak_value, consecutive_count),
    ...
}

工作逻辑:

  • 当无人机开始违规时，创建历史记录
  • 违规持续时，更新峰值和连续帧计数
  • 违规结束时，将记录追加到 result 列表

结果格式:

result = [
    (drone_index, (first_violation_frame, peak_value)),
    ...
]

8.2 查看验证结果

验证结果通过 3D 视图侧边栏 的 Safety Check 面板查看：

  1. 打开 Blender 3D 视图
  2. 按 N 键打开侧边栏
  3. 切换到 "Safety & Export" 标签
  4. 展开 "Safety Check" 面板
  5. 点击 "Validate Trajectories" 按钮执行验证
  6. 验证完成后，各检查项的下拉列表会自动出现，显示违规记录

选择列表中的某一项会自动跳转到对应帧并高亮相关无人机。

9. 常见问题 FAQ

Q1: 加速度阈值应该设置多少？

  • 水平加速度: 默认 1.1 m/s²（适用于小型多旋翼）
  • 垂直加速度: 默认 2 m/s²
  • 具体值取决于无人机性能和负载，建议参考无人机规格手册

Q2: 验证过程很慢怎么办？

  • 减少验证的帧范围
  • 减少无人机数量（使用 selected_only 仅验证选中的无人机）
  • 考虑优化 get_positions 方法，避免逐帧调用 frame_set()

Q3: 为什么加速度需要到第三帧才开始计算？

加速度是速度的变化率，需要至少两帧的速度数据才能计算。而速度本身需要两帧的位置数据。因此：

  • 第1帧：只有位置，无法计算速度
  • 第2帧：可以计算速度，但只有一个速度值，无法计算加速度
  • 第3帧：有了两个速度值，才能计算加速度

代码中通过将 Vxy_previous 和 Vz_previous 初始化为 None 并在首次调用时赋值，实现了从第三帧开始计算加速度的逻辑。
