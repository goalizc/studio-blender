1. 概述

文件路径: src/modules/sbstudio/plugin/panels/hhang.py (第 41-59 行)

功能: 在 Blender 的 Dope Sheet（动画编辑器）中动态过滤显示颜色通道（Color F-Curves）和非颜色通道（位置、旋转等 F-Curves）。提供两个切换按钮，可独立或组合过滤，方便用户在编辑灯光颜色时隐藏位置动画干扰，或在编辑编队轨迹时隐藏颜色动画。

3. 核心逻辑

3.1 更新回调 filter_channels

def filter_channels(self, context):
    for area in bpy.context.screen.areas:
        if area.type == 'DOPESHEET_EDITOR':
            space_data = area.spaces.active
            xor = context.scene.filter_color_channels ^ context.scene.filter_noncolor_channels
            space_data.dopesheet.filter_text = ("楠楠", "颜色")[xor]
            space_data.dopesheet.use_filter_invert = xor ^ context.scene.filter_color_channels

执行流程:

  1. 遍历当前屏幕的所有区域（Areas）
  2. 找到所有 Dope Sheet 编辑器（动画编辑器）
  3. 计算 xor：两个按钮状态的异或
  4. 设置 filter_text：Dope Sheet 的文本过滤器
  5. 设置 use_filter_invert：是否反转文本过滤器

4. 过滤机制详解

4.1 Blender 的文本过滤器原理

Blender 的 Dope Sheet 有一个内置的文本过滤器（Text Filter）：

  • filter_text: 搜索关键字，只显示名称中包含该关键字的 F-Curve
  • use_filter_invert: True = 反转匹配，显示不包含关键字的 F-Curve

在本项目中，无人机的颜色 F-Curve 名称中包含 "颜色"（例如 "颜色" 或包含 "颜色" 的路径），位置/旋转等 F-Curve 名称中包含 "楠楠"（自定义关键字）。

4.2 四种状态组合

颜色通道非颜色通道xorfilter_textuse_filter_invert实际效果
✅ ON✅ ONFalse"楠楠"True显示不包含"楠楠"的通道（全部显示）
✅ ON❌ OFFTrue"颜色"False显示包含"颜色"的通道（仅颜色）
❌ OFF✅ ONTrue"颜色"True显示不包含"颜色"的通道（仅非颜色）
❌ OFF❌ OFFFalse"楠楠"False全不显示

注意: 状态 2 和 状态 3 的实际效果不同：

  • 状态 2：显示"颜色"（颜色通道）
  • 状态 3：显示非"颜色"（非颜色通道）

4.3 状态机转换

默认: 颜色=ON, 非颜色=ON → 显示全部
  xor=False, filter_text="楠楠", invert=True
  → 显示非"楠楠" → 全部

切换"非颜色"→OFF:
  xor=True, filter_text="颜色", invert=False
  → 显示"颜色" → 仅颜色

切换"颜色"→OFF:
  xor=True, filter_text="颜色", invert=True
  → 显示非"颜色" → 仅非颜色

同时OFF:
  xor=False, filter_text="楠楠", invert=False
  → 显示"楠楠" → 全不显示

6. F-Curve 命名约定

6.1 颜色 F-Curve

无人机灯光的颜色 F-Curve 路径中包含 "颜色" 关键字。例如：

color
nodes["Emission"].inputs[0].default_value  ← 可能通过 "颜色" 标识

6.2 非颜色 F-Curve

位置、旋转等非颜色 F-Curve 路径中包含 "楠楠" 关键字。例如：

location
rotation_euler

注意: "楠楠" 是标记关键字占位符，理论上不会存在包含此关键字的任何通道。

7. 实际应用场景

7.1 场景一：编辑灯光颜色动画

需求: 在 Dope Sheet 中仅显示颜色关键帧，隐藏位置/旋转等干扰。

操作: 关闭"非颜色通道"，仅保留"颜色通道"。

效果: Dope Sheet 中只显示颜色相关的 F-Curve，方便精细调整灯光时序。

7.2 场景二：编辑编队轨迹动画

需求: 仅显示位置/旋转关键帧，隐藏颜色动画。

操作: 关闭"颜色通道"，仅保留"非颜色通道"。

效果: Dope Sheet 中只显示位置/旋转相关的 F-Curve，方便编辑编队运动。

7.3 场景三：综合查看

需求: 同时查看所有通道。

操作: 两个按钮都保持开启（默认状态）。

通过 xor 和 invert 的组合，巧妙实现了四种状态的互斥过滤，只需设置两个参数即可覆盖所有组合。

9.2 实时更新机制

update=filter_channels

属性值改变时，filter_channels 回调立即执行。由于直接修改了 Dope Sheet 的 filter_text，所有打开的 Dope Sheet 编辑器会实时刷新显示。

10. 常见问题 FAQ

Q1: 为什么颜色通道包含"颜色"关键字，非颜色通道包含"楠楠"关键字？

这是项目内部的 F-Curve 命名约定。可能在创建动画时通过特定方式标记。如果关键字不匹配，过滤器将无法正确工作。

Q2: 如果两个按钮都关闭会怎样？

根据代码逻辑，两个都关闭时 filter_text="楠楠"，invert=False，实际全不显示任何通道。这是因为不可能有包含此字符串关键字的 F-Curve。

Q3: 过滤器会影响 Graph Editor 吗？

不会。代码仅针对 DOPESHEET_EDITOR 类型的区域。Graph Editor 有独立的过滤器设置。

Q4: 关闭 Blender 后过滤器状态会保留吗？

会。filter_color_channels 和 filter_noncolor_channels 是场景级属性（bpy.types.Scene），随 .blend 文件保存。

Q5: 如果 Dope Sheet 没有打开，过滤器会生效吗？

不会立即生效。但当用户打开 Dope Sheet 时，当前的属性值会保留，下次触发 update 时才会应用过滤。如果需要在打开时自动应用，可以添加额外的区域监听逻辑。
