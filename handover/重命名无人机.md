# RenameOperator 交接文档

## 1. 概述

**类名**: `RenameOperator`
**文件路径**: `src/modules/sbstudio/plugin/operators/rename.py`

**功能**: 为选中的无人机（或全部无人机）按 Y→X→Z 坐标顺序自动重命名为 `Drone 1`, `Drone 2`, `Drone 3`...

---

## 2. 类属性

| 属性 | 值 |
|------|-----|
| `bl_idname` | `skybrush.rename` |
| `bl_label` | Rename |
| `bl_description` | Rename the selected drone |
| `bl_options` | `REGISTER`, `UNDO`（支持撤销） |

---

## 3. 核心逻辑

### 3.1 执行流程

```
poll() → 检查场景中存在无人机集合
    ↓
execute() → 执行重命名
    ↓
1. 确定起始编号（跳过已有的 Drone N 名称）
2. 获取选中无人机，未选中则处理全部
3. 按 Y→X→Z 坐标排序
4. 依次命名为 Drone 1, Drone 2, ...
```

### 3.2 排序规则

```python
key=lambda obj: (obj.location.y, obj.location.x, obj.location.z)
```

按 Y 坐标为主序、X 为次序、Z 为末序升序排列，适合按行排列的无人机编队。

### 3.3 起始编号计算

`start_index` 方法自动检测场景中已有的 `Drone N` 名称，从下一个可用编号开始，避免名称冲突。
