1. 概述

类名: SkybrushRecalculateGroupTakeoffOperator

文件路径: src/modules/sbstudio/plugin/operators/hhang_operators.py

功能: 重新计算分组起飞路径。这是一个自动化一键生成起飞轨迹的复合操作符，内部串联调用多个子操作符（起飞网格分配 → 分组起飞计算 → 故事板过渡生成 → 清理临时数据），最终生成完整的起飞动画。

3. 核心验证逻辑

3.1 执行流程

invoke() → 设置 frame 为当前帧，弹出参数对话框
    ↓
execute() → 开始执行
    ↓
1. 保存原始无人机列表
2. 调用 redistribution_takeoff_grid 分配起飞网格位置
3. 调用 calculate_group_takeoff (dryrun=True) 预计算分组起飞编队
4. 获取无人机在 frame 帧的位置，创建 "group target" 编队
5. 通过故事板系统添加 "group target" 编队条目（dryrun）
6. 设置 target 条目的 frame_start = target_frame
7. 通过故事板系统添加 "group takeoff" 编队条目（dryrun）
8. 设置 takeoff 条目的 frame_start = target_frame + 500
9. 重新计算过渡轨迹 (recalculate_transitions, scope=TO_SELECTED)
10. 跳转到 target_frame + 500，计算缩放后的起飞位置
11. 将缩放后的位置写入帧1的关键帧
12. 正式调用 calculate_group_takeoff 生成分组起飞关键帧
13. 清理临时关键帧（target_entry 的 start/end 帧）
14. 删除故事板条目 "group target" 和 "group takeoff"
15. 删除临时集合 "group target" 和 "group takeoff"

3.2 核心算法详解

步骤1: 起飞网格分配

skybrush.redistribution_takeoff_grid(use_import=self.use_import,
                                     rows=self.rows, spacing=self.spacing)

将无人机分配到网格起飞位置（行优先排列）。

步骤2: 预计算分组起飞

skybrush.calculate_group_takeoff(..., dryrun=True)

以 dryrun=True 模式调用，仅创建 "group takeoff" 编队集合，不插入关键帧。用于获取分组后的高度层信息。

步骤3: 创建目标编队

target_frame = context.scene.frame_end + 100
context.scene.frame_set(self.frame)
for drone in drones:
    points.append(drone.location)
    drone.keyframe_insert(data_path="location", frame=target_frame)
create_formation("group target", points)

在 target_frame（场景末尾+100帧）处为每架无人机插入关键帧，并创建 "group target" 编队。

步骤4: 故事板过渡生成

storyboard = bpy.data.scenes["Scene"].skybrush.storyboard
bpy.data.scenes["Scene"].skybrush.formations.selected = bpy.data.collections["group target"]
skybrush.append_formation_to_storyboard(dryrun=True)
target_entry = storyboard.active_entry
storyboard.active_entry.frame_start = target_frame
bpy.data.scenes["Scene"].skybrush.formations.selected = bpy.data.collections["group takeoff"]
skybrush.append_formation_to_storyboard(dryrun=True)
storyboard.active_entry.frame_start = target_frame + 500
skybrush.recalculate_transitions(scope='TO_SELECTED')

通过故事板系统生成两个编队之间的过渡轨迹。

步骤5: 缩放位置计算

context.scene.frame_set(target_frame + 500)
points = np.array([get_position_of_object(drone) for drone in drones])
center = np.mean(points, axis=0)
points = (points - center) / self.zoom_ratio + center - np.array((self.offset_x, self.offset_y, 0))

将编队位置按 zoom_ratio 缩小并施加偏移，得到起飞前的初始位置。

步骤6: 正式生成分组起飞关键帧

skybrush.calculate_group_takeoff(..., dryrun=False)

使用计算好的初始位置，正式插入所有起飞关键帧。

步骤7: 清理临时数据

self.remove_keyframe(drones, target_entry.frame_start)
self.remove_keyframe(drones, target_entry.frame_end)
self.remove_keyframe(drones, storyboard.active_entry.frame_start)
self.remove_storyboard_entry("group target")
self.remove_storyboard_entry("group takeoff")
remove_objects(bpy.data.collections["group target"])
remove_objects(bpy.data.collections["group takeoff"])

删除所有临时关键帧、故事板条目和集合，只保留最终生成的起飞动画。

3.3 辅助方法

remove_storyboard_entry

def remove_storyboard_entry(self, name):
    try:
        storyboard = bpy.data.scenes["Scene"].skybrush.storyboard
        storyboard.active_entry = storyboard.entries[name]
        skybrush.remove_storyboard_entry()
    except Exception as e:
        print(e)
        self.report({"WARNING"}, f"未成功删除故事版条目: {name}")

通过名称查找并删除故事板条目，失败时输出警告而非中断流程。

remove_keyframe

def remove_keyframe(self, drones, frame):
    for drone in drones:
        drone.keyframe_delete(data_path="location", frame=frame)
        for constraint in drone.constraints:
            constraint = f"constraints[{constraint.name!r}].influence".replace("'", '"')
            drone.keyframe_delete(data_path=constraint, frame=frame)

删除指定帧上的位置关键帧和约束影响关键帧。

8. 常见问题 FAQ

Q1: 为什么需要 dryrun 模式？

dryrun=True 时 calculate_group_takeoff 仅创建编队集合而不插入关键帧。这样可以先获取分组信息和高度层分布，用于后续故事板过渡计算，避免产生不需要的关键帧。

Q2: target_frame 为什么是 scene.frame_end + 100？

选择一个远离实际动画范围的位置（场景末尾+100帧），可以避免与现有动画冲突。这个位置仅用于临时过渡计算，最终会被清理掉。

Q3: 为什么最后要清理临时数据？

"group target" 和 "group takeoff" 是辅助计算的临时编队，对应的故事板条目和关键帧也是中间产物。清理它们可以保持场景干净，只保留最终生成的起飞动画。

Q4: zoom_ratio 为 1 时会跳过什么？

当 zoom_ratio == 1 时（第386行判断 abs(1 - self.zoom_ratio) > 1e-2），跳过缩放步骤，无人机不会在起飞过程中收缩编队范围。
